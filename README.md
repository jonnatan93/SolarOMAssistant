# Solar O&M Assistant

Aplicación desarrollada para automatizar los informes diarios de Operación y Mantenimiento de plantas fotovoltaicas.

## Funciones

- Actualización automática del informe SCADA
- Actualización de gráficas
- Actualización de Gen Medida Vs Esperada
- Automatización de reportes
